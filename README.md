## ✨ Características

- 🌐 **Compatibilidad Total** — Más de 1000 sitios soportados gracias al motor `yt-dlp`
- 🎬 **Múltiples Calidades** — Desde 4K/1080p hasta 480p, o solo audio en MP3
- 📁 **Carpeta Personalizada** — Elige exactamente dónde guardar tus descargas
- 📋 **Cola de Descargas** — Descarga múltiples videos al mismo tiempo
- 📊 **Progreso en Tiempo Real** — Velocidad de descarga, porcentaje y tiempo restante
- 🖱️ **Clic Derecho** — Menú contextual con Copiar, Pegar y Seleccionar todo
- 🎨 **Diseño Futurista** — Glassmorphism, modo oscuro y animaciones fluidas

## 🚀 Instalación y Uso

### Prerrequisitos

- [Node.js](https://nodejs.org/) v18 o superior
- [Git](https://git-scm.com/)
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) instalado en el sistema

#### Instalar yt-dlp en Windows (vía winget):
```bash
winget install yt-dlp.yt-dlp
```

#### Instalar yt-dlp en macOS:
```bash
brew install yt-dlp
```

### Clonar e instalar

```bash
# Clonar el repositorio
git clone https://github.com/Caronte12715/aluro-download-plus.git

# Entrar a la carpeta
cd aluro-download-plus

# Instalar dependencias
npm install
```

### Ejecutar en desarrollo

```bash
npm run dev
```

### Compilar para producción

```bash
npm run build
```

El instalador se generará en la carpeta `release/`.

## 📖 Guía de Uso

1. **Abre la aplicación** — Se verá la pantalla principal de AluroDownload+
2. **Pega el enlace** — Clic derecho → Pegar (o Ctrl+V) en la barra de URL
3. **Configura (opcional)** — Haz clic en el ⚙️ engranaje para elegir:
   - 📁 Carpeta de destino
   - 🎬 Formato: Video (MP4) o Solo Audio (MP3)
   - 📺 Calidad: Máxima, 1080p, 720p o 480p
4. **Descarga** — Haz clic en **Descargar** o presiona `Enter`
5. **¡Listo!** — El archivo aparecerá en tu carpeta seleccionada
